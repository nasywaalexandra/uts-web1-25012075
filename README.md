## 1️⃣ DESKRIPSI APLIKASI

Aplikasi ini digunakan untuk memesan makanan dan minuman di kantin kampus. Data disimpan menggunakan **Session**, tanpa perlu database.

**Fitur Utama:**
- ✅ Menampilkan daftar menu makanan & minuman
- ✅ Pencarian nama menu
- ✅ Filter berdasarkan kategori
- ✅ Simpan kategori favorit
- ✅ Tambah pesanan ke keranjang
- ✅ Validasi input (jumlah kosong, angka, batas maksimal)
- ✅ Gabung jumlah jika pesan menu yang sama
- ✅ Perhitungan otomatis + Diskon 10% (min. Rp 50.000)
- ✅ Hapus satu item / Kosongkan keranjang
- ✅ Data tetap tersimpan saat pindah halaman & refresh
